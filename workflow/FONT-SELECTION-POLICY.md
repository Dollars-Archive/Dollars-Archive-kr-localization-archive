# 한글화 폰트 후보 선정 정책

이 문서는 게임 한글화 작업에서 새 한글 폰트를 선택하거나 기존 폰트를 교체해야 할 때 적용합니다.

기본 후보 검색처:

- https://font.emulog.app/#fonts

Font Share에서 폰트를 찾는다고 해서 아무 폰트나 바로 적용하지 않습니다. 작품마다 실제 폰트 셀 크기, 타일 크기, BPP, 고정폭/가변폭, 글리프 수, 인코딩, 아틀라스 구조, 행간과 베이스라인, VRAM/용량 제한이 다르므로 **게임이 요구하는 실제 규격을 먼저 조사한 뒤 후보를 고릅니다.**

## 1. 먼저 게임의 실제 폰트 규격 확인

가능한 범위에서 다음을 확인합니다.

- 글리프 셀 또는 타일 폭/높이
- 실제 표시 픽셀 크기
- BPP / 팔레트 / 알파 처리
- 고정폭 / 가변폭 여부
- 지원 글리프 수와 한글 범위
- 문자 인코딩 / glyph map
- 폰트 아틀라스 또는 텍스처 배치 방식
- 줄 높이 / 베이스라인 / 자간
- 파일 크기, VRAM, 바이너리 테이블 등 게임별 제약

규격을 모르는 상태에서 폰트 이름이나 외형만 보고 선택하지 않습니다.

## 2. Font Share에서 후보 검색

게임 규격을 확인한 뒤 Font Share의 플랫폼, 타일 크기, BPP, 이름/설명, 라이선스 정보 등을 사용해 후보를 좁힙니다.

가능하면 **서로 성격이 조금 다른 유효 후보 약 3개**를 추립니다.

예:

- 후보 A: 원작 분위기에 가장 가까움
- 후보 B: 작은 픽셀 크기에서 가독성이 가장 좋음
- 후보 C: 획이 굵고 UI/대사창에서 안정적

단, 기술적으로 맞는 후보가 3개 미만이면 숫자를 억지로 채우지 않습니다. 실제로 쓸 수 있는 후보만 제시합니다.

후보 선정 시 우선순위:

1. 게임의 실제 기술 규격과 호환 가능성
2. 한글 가독성
3. 원작 UI/분위기와의 조화
4. 필요한 글리프 범위 충족 여부
5. 라이선스와 재배포 가능 여부

## 3. 동일 조건 샘플 제작

후보를 찾았다고 바로 전체 폰트를 교체하지 않습니다.

각 후보를 **같은 조건**으로 비교할 수 있는 소량 샘플을 만듭니다.

샘플은 가능하면 실제 게임과 같은 픽셀 크기, 같은 셀 크기, 같은 배경/대사창 조건으로 맞춥니다.

샘플 문구에는 가능한 경우 다음을 포함합니다.

- 실제 게임 대사 1~3줄
- 메뉴/UI 문구
- 한글 받침과 복잡한 획이 섞인 문장
- 숫자
- 영문
- 자주 쓰는 문장부호

필요하면 실제 게임 화면에 가까운 목업 또는 최소 테스트 패치를 만들 수 있지만, **사용자 선택 전에는 전체 폰트 교체나 대량 반영을 하지 않습니다.**

## 4. 사용자에게 3안 비교 후 선택 요청

샘플이 준비되면 사용자에게 후보 A/B/C를 나란히 보여주고 짧게 장단점을 설명합니다.

사용자가 직접 최종 폰트를 선택합니다.

```text
후보 A
- 규격: ...
- 장점: ...
- 단점: ...

후보 B
- 규격: ...
- 장점: ...
- 단점: ...

후보 C
- 규격: ...
- 장점: ...
- 단점: ...
```

AI가 임의로 최종 폰트를 확정하지 않습니다.

## 5. 사용자가 고른 폰트를 프로젝트 확정값으로 기록

사용자가 선택한 폰트는 해당 작품의 `AGENTS.md`, 프로젝트 문서 또는 폰트 작업 기록에 **승인된 폰트 기준값**으로 남깁니다.

이후 다른 AI나 서브에이전트가 단순 취향 판단으로 해당 폰트를 임의 변경하지 않습니다.

변경이 필요하면 새 후보와 샘플을 다시 제시하고 사용자 승인을 받습니다.

## 6. 후보가 없을 때

Font Share에서 게임 규격에 맞는 폰트를 찾지 못하면 다음 중 무엇이 필요한지 보고합니다.

- 기존 폰트 리사이즈/재래스터라이즈
- 다른 공개 폰트 변환
- 글리프 일부 보정
- 게임 전용 비트맵 폰트 제작
- 인코딩/폰트 테이블 확장
- 폰트 포맷 리버스 엔지니어링

후보가 없다는 이유만으로 임의 폰트를 강제로 넣지 않습니다.

## 7. 다운로드와 업로드 경계

후보 검토에 필요한 공개 폰트 파일은 실제 라이선스와 배포 조건을 확인한 뒤 사용할 수 있습니다.

Font Share에 새 폰트를 업로드하는 작업은 자동 후속 단계가 아닙니다.

- 사용자가 명시적으로 요청하지 않으면 업로드하지 않음
- 게임 원본에서 추출한 저작권 자산이나 비공개 프로젝트 자료를 업로드하지 않음
- 새로 만든 폰트를 공유할 때도 라이선스와 배포 가능 범위를 먼저 확인

# 한 줄 원칙

**게임의 실제 픽셀/포맷 제약을 먼저 확인하고, Font Share에서 유효 후보 약 3개를 골라 동일 조건 샘플을 만든 뒤 사용자가 직접 최종 폰트를 선택한다.**
