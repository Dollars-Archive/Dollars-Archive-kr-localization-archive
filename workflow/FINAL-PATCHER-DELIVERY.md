# 최종 통합 검수와 배포용 패쳐 제작

## 최종 테스트 파일

최신 원장의 번역·이미지 번역·동영상 자막 작업을 **모두 합친 최종 테스트 파일**과 실행용 `.cmd`를 `04_테스트 파일`에 만든다. 사용자가 초반 1~2시간의 출력·번역·이미지·자막·진행을 확인하고, 발견한 문제는 해당 범위를 수정·재확인한다. 최종 통합본에 이상이 없음을 확인한 뒤 같은 단계에서 최종 패쳐를 만든다. 실기 확인 전에는 합격이나 패쳐 완성을 선언하지 않는다.

## 같은 기종의 기존 패쳐·설명서를 참고

패쳐를 만들기 전에 **`D:/Codex/한글화 프로젝트`에 있는 같은 기종 타이틀의 기존 패쳐와 동봉 설명서**를 찾아 읽는다. 해당 프로젝트의 경로가 다르면 사용자가 지정한 한글화 상위 폴더에서 찾는다. 실행 방식·원본 판별·버전/판본 검사·패치 적용·오류 안내·출력 위치와 설명서 구성을 현재 게임에 맞게 재사용한다.

실제로 참고한 타이틀·기종·패쳐 버전·설명서 경로와 채택한 부분은 내부 작업 기록에 남긴다. 다른 게임의 해시·제품 번호·용량·경로를 복사하지 않는다. 적합한 자료가 없으면 미확인으로 기록하고 현재 게임에서 확인한 적용 방식으로 만든다. 기존 타이틀의 배포물·원본은 수정하지 않는다.

## 배포 설명서에 MD5 필수

설명서에는 **지원 원본과 정상 패치 결과를 식별할 실제 MD5 값**을 반드시 넣는다. 각 값의 대상 파일명 또는 상대 경로, 지원 판본·업데이트와 원본/결과 구분을 함께 적고, 완성한 파일에서 직접 계산한다. 폴더형 게임은 실제 검사 대상 파일별로 명시한다. SHA-256 등 다른 해시를 추가해도 MD5를 생략하지 않는다. 예시 값·미계산 값을 완성 설명서에 남기지 않는다.

설명서에는 지원 기종·판본, 준비물, 실행·적용 순서, 결과 확인 방법, 오류 시 안내를 현재 게임에 맞게 적는다. 패쳐가 검사하는 파일과 설명서의 파일명·MD5가 일치해야 한다.

## 패쳐와 동봉 자료는 모두 배포용

최종 패쳐·ZIP·설명서는 **배포용 산출물**로 만든다. 개인 실명·연락처, Windows 사용자명·계정 경로, 개인 드라이브 절대 경로, 비공개 Drive/세션 링크·대화 ID, 토큰·키·인증 정보와 이런 정보가 담긴 작업 로그·디버그 자료를 넣지 않는다. 다른 사용자의 환경에서도 동작하도록 상대 경로·파일 선택을 사용한다. 로컬 참고 경로와 내부 인계 기록은 공개 설명서에 복사하지 않는다.

묶음을 완성한 뒤 실제 배포 ZIP을 풀어 내용·설명서·실행 파일의 문자열/메타데이터에 개인 정보가 남지 않았는지 필요한 범위에서 확인하고, 풀어낸 패쳐를 별도 원본 사본에 적용해 결과 MD5를 대조한다. 수정이 필요하면 해당 산출물만 고치고 재확인한다. 원본 게임 데이터와 개발용 임시 자료는 배포 묶음에 포함하지 않는다.

최종 패쳐·배포 묶음은 `05_한글 패치 배포`, 완료 자료는 `06_한글 패치 완료`에 정리한다. 최종 패쳐 제작과 공개 업로드는 구분하며, 실제 게시 여부는 사용자가 지시한 승인 범위를 따른다.
