# 모든 한글화 프로젝트의 전용 에뮬 공통 설정

이 설정은 신규·진행 중 모든 한글화 프로젝트에 같은 기준으로 적용한다. 3번 한글패치 조사 다음, 4번 롬 분석 전에 3-1단계로 수행한다. 이미 설정된 프로젝트는 실제 값과 확인 기록을 점검한다.

## 경로와 확인 순서

1. 사용자가 `00_원본`에 원본 롬, `08_전용_에뮬`에 포터블 에뮬을 복사했는지 확인한다. 복사 전에는 등록 대기와 넣을 경로를 안내한다.
2. 설정·메모리카드·세이브·게임별 설정이 프로젝트 안에 저장되도록 분리한다. 공용 설정과 기존 세이브는 보존한다.
3. 에뮬의 기본 롬 탐색 폴더·게임 목록 경로를 해당 게임의 `04_테스트 파일`로 설정한다. 원본 롬은 `00_원본`에 보존하고 테스트 롬을 `04_테스트 파일`에 만든다. 테스트 파일이 아직 없어도 경로는 이 폴더로 지정한다.
4. 아래 키보드 배치를 적용한다. 에뮬마다 버튼 이름이 달라도 위치와 기능을 기준으로 대응한다. 지원하지 않는 버튼·스틱은 생략하고 대응 결과를 기록한다.
5. 설정 파일을 저장하고 다시 읽는다. 에뮬을 재실행해 경로와 키 배치가 유지되는지 확인한다. 가능하면 입력 시험으로 확인하고 직접 실행할 수 없으면 사용자 확인 대기로 남긴다. 설정을 쓰기만 한 상태를 실행 확인 완료로 표시하지 않는다.
6. 확인 기록과 다음 작업 프리뷰를 보고한다. 완료 후 4단계 분석 담당(Claude/Codex)을 확인한다.

## 기본 키보드 배치

| 컨트롤러 기능·위치 | 키보드 |
|---|---|
| 방향키 위 / 아래 / 왼쪽 / 오른쪽 | ↑ / ↓ / ← / → |
| 페이스 버튼 위 / 왼쪽 / 아래 / 오른쪽 | W / A / S / D |
| L1 또는 L / L2 / L3(왼쪽 스틱 누르기) | Q / Z / F |
| R1 또는 R / R2 / R3(오른쪽 스틱 누르기) | E / C / G |
| Select 또는 Back / Start | N / M |
| 왼쪽 스틱 위 / 왼쪽 / 아래 / 오른쪽 | U / H / J / K |
| 오른쪽 스틱 위 / 왼쪽 / 아래 / 오른쪽 | P / L / `;`(세미콜론) / `'`(작은따옴표) |

페이스 버튼은 명칭 대신 **화면상의 위치**를 기준으로 맞춘다. 예를 들어 PS의 △/□/×/○는 W/A/S/D이다. 불확실한 버튼 대응은 추측하지 않고 해당 에뮬에서 확인한다. 추가 기능 키는 이 기본 배치와 충돌하지 않게 정한다.

진행상태에는 에뮬·버전, 실행 경로, 롬 탐색 경로, 설정·세이브 경로, 버튼 대응·생략 항목, 재실행·입력 확인 결과를 기록한다. 다른 프로젝트에서도 같은 키 배치를 기본으로 사용한다. 사용자에게 매번 키를 하나씩 입력하라고 요구하지 않는다.
