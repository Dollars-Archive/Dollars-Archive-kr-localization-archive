# 실제 플레이 검수 피드백 정책

## 1. 최종 권위 순서

한글화 검수에서 판단 근거의 우선순위는 다음과 같습니다.

1. 실제 게임 플레이 중 사용자가 직접 확인하고 확정한 수정
2. 게임 내 실제 문맥과 대사 근거
3. 등록된 용어집·캐릭터 정보·관계도·말투 규칙
4. AI 분석 또는 번역 제안

AI는 검수 후보를 제시할 수 있지만 더 강한 근거를 자동으로 덮어쓰지 않습니다.

## 2. 플레이 확정값 기록

사용자가 실제 플레이 중 수정안을 확정하면 게임 전용 검수 프로그램에 다음 정보를 남길 수 있어야 합니다.

- 대사/자산 ID
- 기존 값
- 확정 값
- 수정 분류
- 장면 또는 문맥 메모
- 확정한 이유
- 관련 캐릭터
- 공통 규칙으로 승격할지 여부

## 3. 재사용 가능한 규칙으로 승격

플레이 중 발견한 수정이 한 문장에만 해당하지 않고 반복 가능한 규칙이라면 별도로 등록할 수 있습니다.

예:

- 특정 캐릭터가 특정 인물에게 항상 존댓말
- 특정 호칭의 고정 번역
- 특정 시점 이후 관계 변화
- 특정 캐릭터의 반복 말버릇

다만 규칙으로 승격했다고 해서 기존 전체 대사를 자동으로 일괄 재작성하지 않습니다.

권장 흐름:

```text
플레이 중 발견
→ 사용자 확정
→ 규칙 후보 등록
→ 관련 행 검색
→ 검수 후보 생성
→ 사용자/후속 검수에서 승인
```

## 4. AI 자동 수정 제한

다음 항목은 AI 판단만으로 최종 확정하지 않는 것을 기본으로 합니다.

- 반말/존댓말 관계
- 호칭 변화
- 캐릭터 관계 변화 시점
- 복선이나 중의적 표현
- 실제 화면에서만 확인 가능한 RSC/줄바꿈 문제

AI 분석은 검수 후보와 근거를 제공하는 역할로 사용합니다.

## 5. 이력 보존

검수 프로그램은 가능하면 다음 상태를 구분합니다.

- AI 제안
- 검수 중 채택
- 사용자 플레이 확정
- 이전 규칙 대체
- 미해결 후보

나중에 왜 번역이 바뀌었는지 추적할 수 있어야 합니다.

## 6. 후속 검수 반영

플레이 확정값은 이후 Google Drive 검수 기준자료를 개선하는 데 사용합니다.

예:

- `glossary.csv` 업데이트
- `relationships.csv` 업데이트
- `speech_style.csv` 업데이트
- `characters.csv` 보완

단, 이미 완료한 다른 문장을 근거 없이 자동 변경하지 않습니다. 새 규칙과 충돌하는 행을 후보로 찾아 후속 검수 대상으로 올리는 방식이 안전합니다.
