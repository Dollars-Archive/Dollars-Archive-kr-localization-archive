# 1차

공통규칙.md와 게임정보.md를 읽고 최신 용어집·캐릭터·관계·사용자 확정값을 확인한다.
03_1차_검수_CSV의 지정 CSV 1파일 전체를 처리한다.
번역이 없으면 해당 행의 일본어·영어 원문에 충실하게 초벌 번역한다. 번역이 있으면 오역·누락·용어 오류를 고친다.
특히 캐릭터 이름·스킬명·아이템명·시스템 메시지는 일본어 원문을 직접 확인하고, 뜻이나 표기를 혼자 추측해 확정하지 않는다. 다른 게임·애니메이션에서 같은 이름·용어·메시지를 한국어로 어떻게 표현하는지 확인한다. 공식 한국어 표기와 널리 쓰이는 표현을 우선 참고하되, 이 게임의 원문 의미·문맥에 맞는지 대조한다. 다른 작품에서 다른 뜻으로 쓰인 표현을 그대로 가져오지 않는다.
참고한 표현과 출처는 해당 row_key의 메모나 용어 후보에 남긴다. 사용자 확정값은 유지하고, 통용 표현을 확인하지 못했거나 표기가 충돌하면 후보·보류로 남긴다. 확인하지 않은 표현을 통용 표기라고 단정하지 않는다.
캐릭터 이름과 원문에서 두 번 이상 반복되는 고유명사(아이템·장소 등)는 용어집에 기록한다. 이름과 용어도 해당 행의 원문에 충실하게 번역하고 근거 row_key를 남긴다.
게임 대사창의 화자 표시와 추출된 화자 정보를 함께 확인한다. 근거가 확실한 경우만 화자를 입력하고, 불확실하면 빈칸으로 두고 메모한다. 화자는 2차·3차에서 다시 확인한다.
일본어 행은 일본어 원문을 먼저 읽고, 어려운 표현은 영어판 대조 후보로 기록한다. ROM에 영어로 쓰인 항목은 그 영어 원문을 직접 번역한다.
같은 파일명으로 04_2차_검수_CSV에 저장하고 재확인한 뒤 진행표를 갱신한다.
1차 전체가 끝나면 용어·인물 후보를 정리해 2차의 공통 기준을 만든다.

## 입력·출력

- 입력: `03_1차_검수_CSV/<카테고리>/<파일명>.csv`
- 출력: `04_2차_검수_CSV/<같은카테고리>/<같은파일명>.csv`
- 범위: 사용자 지정 CSV 1파일의 모든 논리 데이터 행, 최대 500행. 헤더는 제외한다.
- 전체 원장·스키마·실제 입력 파일이 준비됐는지 확인한 뒤 시작한다. 공통규칙·게임정보·출력규격·최신 용어·인물·관계 마스터·사용자 확정값을 먼저 읽는다.

## 수행 조건

빈 한국어 번역만 있어도 원문 전체를 읽고 모든 행을 번역한다. 출력 폭이나 시험 대사의 바이트 수에 맞추려고 초벌부터 의미를 생략하지 않는다.

새 이름과 두 번 이상 반복되는 고유명사는 근거 `row_key`와 적용 범위를 용어 후보에 기록한다. 캐릭터의 이름·1인칭·관계·말투를 이 단계에서 추측으로 확정하지 않는다. 화자는 명시 표시나 연결 근거가 확실한 경우만 보강한다.

일본어·영어 원문 모두 처리한다. 같은 게임의 영문 자료가 실제로 등록돼 있을 때만 대조하며, 없는 영어판 내용이나 출처를 만들어내지 않는다.

각 행의 원문·키·순서·토큰·보호 열을 보존한다. 검수 상태는 해당 게임의 실제 스키마가 허용하는 값만 쓴다.
