# 1차: 대사 초벌이 아닌 5종 용어 사전 확정

**이 단계는 대사 번역·초벌 검수 단계가 아니다.** 원문을 읽어 캐릭터·아이템·스킬·시스템 용어·고유명사를 본번역 전에 확정하는 단계다. `1차 검수 CSV` 또는 `1차 완료`된 대사 번역본을 만들지 않는다.

## 입력·출력

- 입력: `00_전체원장`의 원문/원본 위치, `03_2차_원문_CSV`를 포함한 읽기 전용 추출 자료, 기존 공식 번역·사용자 확정값·게임정보.md·출력규격.md.
- 출력: `01_최신_용어집/캐릭터_확정용어집.csv`, `아이템_확정용어집.csv`, `스킬_확정용어집.csv`, `시스템_확정용어집.csv`, `고유명사_확정용어집.csv`. 출처·근거·후보·승인 및 버전/해시 기록을 함께 보존한다.
- 선택 자료: `캐릭터.csv`(이름 대응은 확정, 성격/일인칭/말투는 근거가 생길 때까지 공란), `관계_말투.csv`(대사 확인 전에 관계를 추측 기입하지 않음), `사용자_확정값.csv`.
- **금지:** `03_1차_검수_CSV` 생성, 대사 전량 초벌 번역, 대사에 `1차 완료` 일괄 표시, 임의로 사용자의 확정 표기 변경.

## 조사·확정 순서

1. 게임명·플랫폼·판본·언어·원장 범위·중복 키와 원본 위치를 확인한다. 원문의 대상 영역을 카테고리/명칭/문장으로 구분한다. 표시 여부가 불확실한 텍스트는 별도 조사 대상으로 남긴다.
2. **캐릭터:** 이름·별칭·칭호·집단/유닛명을 조사한다. 원문 철자·동일 인물 여부·게임 내 표시·공식 명칭·등장 근거를 구분한다. 성격, 존대/반말, 인물 관계를 이름만으로 창작하지 않는다.
3. **아이템·스킬:** 이름·분류·효과·설명·사용자/장면을 대조해 동일 명칭과 동명이의어를 구분한다. 확정해야 할 명칭은 1차에 고정한다. 번역 대상인 긴 설명·대사까지 1차 초벌로 번역하지 않는다.
4. **시스템:** 메뉴·전투·UI·튜토리얼의 고정 명칭/반복 용어를 조사한다. 완전한 안내문·시스템 메시지 등 문장형 텍스트는 이미 승인된 고정 번역이 없는 한 2차·3차에서 처리한다.
5. **고유명사:** 장소·조직·세계관·설정·세계/종족/직책·기타 반복 가능한 작품 고유 용어를 대사 원문까지 검색한다. **한 번만 등장해도 후보에 포함**하고 원문에서의 실제 의미·대응을 확인한다. 출현 수는 같은 `row_key` 및 텍스트 위치를 중복 제거해 집계한다. '두 번 이상 등장해야 확정 가능'이라는 전 게임 공통 제한은 사용하지 않는다.
6. 아래 공통 조사 순서를 지킨다: **나무위키·국내 기사·연재 글 → 없으면 해당 게임 영어판·영문 자료 → 그래도 없으면 국내 다른 게임·애니메이션·소설·만화의 보편 표기**. 실제 원문·동일 대상·문맥과 출처를 확인하고, PC AI 한패는 보조 자료로만 사용한다. 미확정·충돌은 보류하며 사용자 확정값은 보호한다.
7. 각 항목에 `원문 / 한국어 확정값 / 범주 / 의미 및 적용 범위 / 원본 위치 및 row_key / 공식 또는 실제 문맥 근거 / 결정권자 / 결정일 / 확정·보류 상태`를 기록한다. 하나의 일본어 표현이 여러 뜻이라면 적용 범위를 나눈다.
8. 담당자별 후보는 개인 작업 파일에 기록하고, 총괄만 검증하여 공용 용어집에 통합한다. **임의 병렬 덮어쓰기 금지.** 동결 대상 파일의 버전·SHA-256·적용 게임/판본을 기록하고 승인한 기준만 2차에 제공한다.

## 2차 시작 게이트

- 다섯 범주의 **본번역에 필요한 핵심 용어**가 사용자 또는 지정 결정권자의 근거 있는 승인으로 확정되고 버전 고정됐는지 확인한다.
- 미확정 후보는 확정값과 명확히 구분한다. 번역을 바꾸는 핵심 명칭이 해결되지 않으면 해당 범위의 2차를 보류하고 판단 근거를 요청한다. 증거 부족한 명칭을 억지로 확정하거나 마치 누락이 없는 것처럼 숨기지 않는다.
- 2차 입력 원문 CSV의 `row_key`, 행 수, 원문 언어, 원본 위치와 보호 열을 재확인한다. 대사 번역문은 공란이어도 정상이다.
- 용어 완료 여부는 진행표의 `1차 용어 확정` 게이트로 기록한다. 대사 행 상태값에 1차 완료를 쓰지 않는다.

**결과:** 동결된 5종 용어집과 출처·보류 기록을 2차에 넘긴다. 1차 대사 번역 CSV는 존재하지 않는다. 후속 흐름은 2차 본번역 → 3차 독립 검수 → [4차 줄바꿈·공란·일본어 잔존 확인](4차.md)이며, 용어 선확정을 이유로 대사 배치 작업을 앞당기지 않는다.

## 용어집 조사 순서 — 모든 게임 공통 (사용자 규칙, 2026-10-18)

신규 게임과 진행 중 게임의 미확정 이름·고유명사·용어를 조사할 때 다음 순서를 적용한다.

1. **나무위키·국내 사이트 기사·국내 연재 글 등 한국어 자료**에서 해당 작품·시리즈·인물·개체·개념의 실제 표기를 먼저 확인한다.
2. 국내 자료에서 대응 표기를 찾지 못하면 **실제로 존재하는 해당 게임의 영어판·영문 자료**를 참고한다.
3. 그래도 대응 표기를 찾지 못하면 **국내 다른 게임·애니메이션·소설·만화 등에서 보편적으로 쓰는 이름·고유명사 표기**를 조사한다.

- 다른 작품의 자료는 동일 인물·개체·개념·원어 독음과 실제 게임 문맥이 대응하는 경우에만 적용한다. 철자나 한자가 같다는 이유만으로 다른 대상을 자동 이식하지 않는다.
- 기존 PC AI 한글패치·기계번역은 보조 후보 자료다. 그 표기나 출현 빈도만으로 확정하거나 국내 통용 표기라고 단정하지 않는다.
- 실제 확인한 출처 URL·문서 제목·사용 표기·확인일·대응 근거와 원문·원본 위치·row_key를 남긴다. 검색하지 않은 자료, 존재하지 않는 영어판·공식 번역·사용례를 만들지 않는다.
- 접근 제한이나 검색 실패는 '표기 없음'의 증거가 아니다. 다른 자료를 확인하고, 근거 부족·상충은 미확인/보류와 결정에 필요한 근거로 기록한다.
- 사용자 확정값과 이미 승인·동결한 용어는 보호한다. 이 조사 순서 변경을 기존 확정 용어의 일괄 변경 승인으로 해석하지 않는다. 해당 작업에서 위임된 확정 권한 안에서 선정하며, 미해결 핵심 표기는 묶어서 보고한다.
- 새 프로젝트용 공통규칙·1차 지시문·용어집 출처 양식과 Drive 인계 자료에도 이 순서를 반영한다. 담당 모델이나 게임 기종에 따라 임의로 바꾸지 않는다.
