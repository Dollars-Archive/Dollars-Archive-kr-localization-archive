# 시작하기

먼저 공통작업지시문.md·작업순서.md·진행상태.md를 읽고 현재 단계가 9번인지 확인한다.

1. 게임정보.md와 공통규칙.md, 이번 차수의 지시문을 읽는다.
2. 최신 용어집·캐릭터·관계·사용자 확정값을 확인한다.
3. 이번 차수 입력 폴더의 CSV 하나를 골라 전체를 처리한다.
4. 같은 파일명으로 다음 차수 폴더에 저장하고 다시 열어 확인한다.
5. 진행표를 갱신한다. 전 파일 처리 후 후보를 정리하고 다음 차수로 간다.
3차 결과는 06_3차_완성본_CSV에 저장한다.

게임정보.md에는 실제 Drive 파일 링크를 넣는다. 파일 저장·권한이 없으면 결과를 저장했다고 말하지 않고 필요한 연결을 알린다. 차수별 진행은 진행표.csv에, 전체 16단계 상태는 진행상태.md에 기록한다.
