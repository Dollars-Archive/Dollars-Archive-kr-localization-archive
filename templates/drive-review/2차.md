# 2차: 원문 기반 최초 본번역 + 캐릭터·관계·말투 근거 구축

**2차가 대사·문장형 텍스트의 첫 본번역 단계다.** 1차 대사 초벌 번역은 없다. 기존 번역이 일부 있어도 원문에서 독립적으로 뜻을 판단한다.

## 시작 조건·입출력

- 선행 조건: [1차 용어 선확정](1차.md)의 5종 확정 용어집, 범위·승인 기록, 사용자 확정값과 원장/원문/게임정보/출력규격 준비 확인.
- 입력: `03_2차_원문_CSV/<카테고리>/<파일명>.csv`.
- 출력: `04_3차_검수_CSV/<같은카테고리>/<같은파일명>.csv`. 이는 **2차에서 완성한 본번역을 3차가 받을 입력본**이지 3차 완료본이 아니다.
- 처리 단위: 지정 CSV 1파일의 **헤더 제외 최대 500논리 데이터 행 전부**. 이름·설명·대사 등 카테고리는 원장에 있는 대상만 처리한다. 같은 장면·분기의 작은 연속 묶음으로 읽되, 파일의 누락 행이 없어야 한다.

## 행별 수행 순서

1. `공통규칙.md`, `게임정보.md`, `출력규격.md`, 5종 동결 용어집, 사용자 확정값과 사용 가능한 인물/관계 후보를 읽는다.
2. **원문 먼저:** 일본어 또는 영어 **실제 원문**, 같은 장면·분기의 앞뒤 문맥·분기·화자 표시·제어 구조를 확인한다. 원문 파일 경계라면 전체 원장/인접 파일을 참조한다. 다른 분기나 실행 순서 미확정 장면은 이어 붙이지 않는다.
3. **독립 해석:** 누가 누구에게 말하는지, 주어·목적어·지시어·생략·부정·시제·가정·확정/추측·명령/질문·반어·감정·복선을 원문에 맞춰 판단한다. 영어 참고판이 있을 경우 실제 동일 장면 대응을 확인하며 일본어 원문을 영어 번역으로 대체하지 않는다.
4. **한국어 본번역:** 동결된 캐릭터·아이템·스킬·시스템·고유명사 표기를 적용하고, 의미·태도·존대/반존대/반말/독백을 정확하게 옮긴다. 모르는 의미를 지어내거나 누락해 매끄럽게 보이게 만들지 않는다. 기본적인 한국어 자연스러움은 확보하되 세밀한 어휘 선택·리듬은 3차에서 최종 조정한다.
5. **기존 번역이 있으면 나중에만 비교:** 기존 초벌/부분 번역을 원문 해석의 기준으로 삼지 않는다. 정확한 문장은 유지할 수 있지만 오역이면 통째로 새로 쓴다. '명백한 오역만 고친다'는 제한 없이 **모든 행의 의미**를 검증한다.
6. **성격·관계 증거 수집:** 확인된 화자·청자, 일인칭·기본 말투·성격, 서로 부르는 호칭, **화자→청자 방향**, 존대/반존대/반말·독백, 장면/루트/스토리 시점, 변화 근거 `row_key`를 개인 후보 파일에 기록한다. 일시적인 감정을 영구 성격으로 만들거나 후반 관계를 초반에 적용하지 않는다. 추정 화자·청자를 확정하지 않는다.
7. 새 용어·고유명사의 출현, 표기 충돌, 동결값 오역 의심은 출처·영향 `row_key`와 함께 총괄에게 정정 후보로 보고한다. 서브가 동결된 용어집이나 사용자 확정값, 공유 캐릭터·관계 CSV를 직접 수정하지 않는다.

## 품질·출력 검증

- 번역 누락, 남은 원어(의도적으로 남긴 경우 제외), 의미 반전/주체 변경/정보 추가, 말투 오류, 확정 용어 불일치를 전 행 점검한다.
- 게임별 확인된 화면 폭/최대 줄/줄바꿈/문자 매핑/저장 인코딩/RSC 조건에 맞는 번역·줄바꿈 후보를 만든다. **미측정 조건을 추정해 PASS 처리하거나 의미를 줄여 맞추지 않는다.** 삽입·실기 적합성은 별도 기술 상태다.
- 원문·`row_key`·순서·원본 참조·토큰·보호 열은 변경 금지. 게임정보에 명시된 수정 가능 열만 변경하고, `review_status`는 실제 허용값 `2차 완료` 또는 `보류` 등만 사용한다.
- 저장 후 재개방하여 행 수·고유 키·첫/마지막 행·보호 열·미해결 사유를 검사한다. 파일마다 진행표를 갱신하고 승인된 같은 차수의 다음 파일을 이어서 처리한다. 사용자가 하나만 지정한 경우 지정 범위만 처리한다.

## 2차 전체 완료 → 3차 확정기준 생성

전 파일의 2차 저장 및 보류 기록을 검증한 **다음에만** 총괄이 담당자별 성격·일인칭·말투·방향별 관계·시간대별 호칭 변화를 취합한다. 출처와 범위가 확인된 규칙만 확정하고, 충돌·미상 후보는 별도로 둔다. 선확정 용어집의 버전/해시를 포함해 `01_최신_용어집/3차_확정기준/`에 최종 스냅샷을 기록한다. **그 전에는 3차 팀을 시작시키지 않는다.**

2차 완료는 정확한 의미와 기본 말투를 갖춘 **언어 본번역**의 완료이지 게임 삽입·실기 합격이 아니다.
