# 3차

공통규칙.md와 게임정보.md, 3차_확정기준과 사용자 확정값을 읽는다.
05_3차_검수_CSV의 지정 CSV 1파일 전체를 **처음부터 다시 번역하며 검수**한다. 2차본은 정답이 아니라 비교 대상이다. 모든 데이터 행을 원문에서 다시 확인하며, 2차 완료 표시나 용어집 등록만으로 통과시키지 않는다.
각 행은 **원문·앞뒤 문맥 확인 → 독립적으로 번역 판단 → 2차본과 비교 → 오류 수정 또는 유지 근거 확인** 순서로 처리한다. 일본어 행은 일본어 원문을 먼저 읽고, 영어 원문 행은 그 영어를 직접 확인한다. 대사는 같은 장면·분기의 앞뒤 2~4문장으로 의미·화자·청자·관계를 다시 확인한다. 1·2차의 오역·누락·화자·용어·관계·말투 오류를 찾아 고친다. 원문을 다시 확인해 정확한 번역은 유지할 수 있지만, 무조건 다른 표현으로 바꾸거나 2차본을 그대로 복사해 검수 완료로 처리하지 않는다.
앞서 게임에서 확인한 최대 줄 수·최대 칸 수와 RSC 제한·초과 허용 여부를 기준으로 대사를 수정한다. 초과가 허용된 경우도 검증된 범위 안에서만 적용한다. 확인하지 않은 조건을 임의로 허용하지 않는다.
2차에서 정리한 용어집의 의미·적용 범위도 원문과 다시 대조한 뒤 고유명사와 캐릭터 이름을 통일한다. 확정 표시가 있다는 이유로 잘못된 뜻이나 표기를 유지하지 않는다.
1차와 마찬가지로 캐릭터 이름·스킬명·아이템명·시스템 메시지는 일본어 원문을 직접 확인하고, 뜻이나 표기를 혼자 추측해 판단하지 않는다. 다른 게임·애니메이션의 공식 한국어 표기와 통용 표현을 확인해 이 게임의 원문 의미·문맥과 대조한다. 다른 작품에서 다른 뜻으로 쓰인 표현을 그대로 가져오지 않는다. 참고 표현과 출처는 해당 row_key의 메모나 용어 후보에 남긴다.
1·2차 오류를 수정할 때는 근거 row_key와 수정 이유를 메모에 남긴다. 공용 용어집·화자·관계 기준의 오류는 정정 후보로 함께 보고해 전체 파일에 일관되게 반영할 수 있게 한다. 사용자 직접 확정값과 충돌하면 임의로 덮어쓰지 않고 근거와 수정 후보를 보고한다. 근거가 부족하면 보류하고 확인하지 않은 표현을 통용 표기라고 단정하지 않는다.
2차에서 확정한 캐릭터 성격·말투와 화자→청자 관계를 참고해 대사를 수정한다. 장면에 맞는 반말·존댓말·호칭·감정을 반영하면서 일본어 원문의 의미를 유지한다.
원문과 번역을 대조해 공란·번역 누락·남은 일본어 등 미번역이 없는지 확인한다. 의도적으로 남긴 원어는 미번역과 구분해 근거를 기록한다. 오역·띄어쓰기·줄바꿈도 최종 확인한다.
1·2차 후보나 다른 게임의 표현은 참고 근거로만 사용하고 새 확정 기준으로 섞지 않는다. 일본어 행의 기준을 영어판으로 바꾸지 않는다.
미해결 항목은 이유를 남긴다. 사용자 확인 없는 추정값을 사용자 확정으로 기록하지 않는다.
같은 파일명으로 06_3차_완성본_CSV에 저장하고 재확인한 뒤 진행표를 갱신한다.
3차 전체 종료 후 row_key로 합친 최종 누적 CSV를 Drive에 저장한다.
이는 언어 검수 완료이며 실제 게임 실행 검증 완료와 구분한다.

## 입력·출력

- 입력: `05_3차_검수_CSV/<카테고리>/<파일명>.csv`
- 출력: `06_3차_완성본_CSV/<같은카테고리>/<같은파일명>.csv`
- 범위: 사용자 지정 CSV 1파일의 모든 논리 데이터 행, 최대 500행. 헤더는 제외한다.
- 전체 원장·스키마·실제 입력 파일과 `3차_확정기준`을 확인한다. 공통규칙·게임정보·출력규격·최신 마스터·사용자 확정값을 먼저 읽는다. 확정 기준이 준비되지 않았다면 2차 통합을 확인하고 3차 시작을 보류한다.

## 수행 조건

모든 행을 원문과 같은 장면·분기의 앞뒤 2~4문장에서 독립적으로 다시 번역해 판단한 뒤 2차본과 비교한다. 정확한 번역은 재확인 후 유지할 수 있다. 오역·누락·화자·용어·관계·말투·띄어쓰기·줄바꿈을 다시 확인하고 수정 이유와 근거 `row_key`를 메모한다.

최대 줄 수·가로폭·칸 수는 해당 게임에서 확인한 **화면·문자열 종류별 규격**을 따른다. 대사창의 값을 이름·메뉴·설명에 일괄 적용하지 않는다. 띄어쓰기·반각/전각 공백도 검증된 정책을 따르며 임의의 넓은 공백으로 정렬하지 않는다.

RSC·본문 바이트 예산은 실제 게임 저장 인코딩과 해당 행의 원문·제어 구조를 기준으로 계산한다. UTF-8 CSV 파일 길이나 화면 칸 수로 대체하지 않는다. 종료 문자·제어 코드의 포함 여부와 문자별 바이트 수는 게임정보·출력규격에 명시된 기준을 따른다. 시험 대사 한 행의 예산을 다른 행이나 게임 전체의 상한으로 사용하지 않는다.

줄바꿈은 해당 게임에서 확인한 토큰·코드를 사용한다. 원래 토큰과 종료 구조를 보존하고, 실제 LF·`[n]`·HTML 태그 등을 임의로 대체하거나 새 제어 기호를 넣지 않는다. 원문 토큰을 번역 문구로 오인해 제거하지 않는다.

문자 매핑·지원 글자·행별 예산·출력 조건이 확인되지 않았다면 삽입 적합성을 PASS로 표시하지 않고 기술 확인 보류를 남긴다. 언어 검수와 기술 확인 상태를 구분한다.

3차 전체 종료 후 최종 CSV·병합 원장·용어 및 관계 기준·사용한 지시문을 로컬 `03_검수_자료/02_3차 검수 완료`에 보관한다. Drive의 폴더 구분과 카테고리·파일명을 유지해 가져오고, 최종 병합은 `row_key`로 수행한다. 이는 검수 프로그램 적용이나 게임 전체 실기 합격을 의미하지 않는다.
