# 3차: 원문 독립 재검증 + 최종 번역 완성

**3차는 2차 교정본을 정답으로 받아들이지 않는다.** 원문부터 전 행을 독립적으로 다시 판단한 뒤 2차본과 대조해 정확성과 자연스러움을 최종 검수한다. '1차 대사 번역'은 존재하지 않는다.

## 시작 조건·입출력

- 선행 조건: 2차 모든 파일의 완료/보류 근거·재개방 검증·팀별 기준 통합, `01_최신_용어집/3차_확정기준/`의 버전·근거·적용 범위 고정. 이 기준이 없으면 시작하지 않는다.
- 입력: `04_3차_검수_CSV/<카테고리>/<파일명>.csv`와 5종 동결 용어집·캐릭터/관계·말투의 확정기준.
- 출력: `05_4차_검수_CSV/<같은카테고리>/<같은파일명>.csv`. 4차가 입력받을 언어 검수본이며 최종 완료 폴더는 아니다.
- 범위: 지정 파일의 **헤더 제외 모든 논리 데이터 행**, 기본 최대 500행. 가능하면 2차 담당자와 다른 작업자가 독립 검수한다.

## 행별 필수 검수

1. `공통규칙.md`, `게임정보.md`, `출력규격.md`, 원본/원장과 사용자 확정값, 동결 5종 용어집, `3차_확정기준`을 읽는다.
2. **2차 번역을 판단 기준으로 먼저 읽지 않는다.** 실제 일본어/영어 원문·같은 장면/분기 문맥을 보고 의미, 주체·대상, 부정·가정·시제, 화자·청자, 호칭과 감정·어조를 독립적으로 판단한다. 다른 분기·미확정 스토리 순서를 연결하지 않는다.
3. 독립 판단과 **2차 번역을 비교**한다. 오역·의미 반전·누락·원문에 없는 정보·인물 관계/존대 오류·고유명사 오류를 수정한다. 정확한 번역은 유지할 수 있다. 무조건 바꾼 표현 수를 성과로 삼거나 검수 없이 2차본을 복사해 통과시키지 않는다.
4. 동결 용어와 캐릭터별 성격·기본 말투, **화자→청자 방향·시점/장면별 관계 변화**를 대조한다. 자연스러운 한국어, 어순·어휘·문장 리듬·존댓말/반말·독백·감정·띄어쓰기·구두점·줄바꿈을 다듬되 원문에 없는 욕설·친밀감·사실·설명은 추가하지 않는다.
5. 이름·아이템·스킬·시스템·고유명사는 **1차 선확정 표기**를 지킨다. 의미상 오류나 신규 증거가 있다면 원문·실제 출처·변경 후보·영향 `row_key`를 총괄에게 보고한다. 사용자 확정값이나 공동 기준을 개인이 몰래 고치지 않는다. 다른 게임/영문판 표현은 실제 대응이 검증된 경우 비교 근거로만 쓴다.
6. 각 행의 공란·미번역·남은 원어(의도적 표기와 구분), 보호 토큰 손실·서식 문제·적용 범위 오류를 다시 확인한다. 근거가 부족하면 보류하고 이유를 남긴다.

## 게임별 기술 규칙과 저장

- `출력규격.md`에서 **이 게임에 대해 검증된** 화면/문자열 종류별 가로폭·표시 줄 수·폰트/지원 문자·줄바꿈 코드를 사용한다. 한 대사창의 기준을 이름·메뉴·설명에 일괄 적용하지 않는다.
- 바이트/RSC는 실제 인코딩·문자 별칭·원래 명령/제어/종료 구조에 따라 계산한다. UTF-8 CSV 바이트 수나 보편적인 '한글 n글자' 한도로 대체하지 않는다. 다른 게임의 시험값을 이 게임에 적용하지 않는다.
- 기술 조건이 미확정이라면 언어상 적절한 번역과 기술 보류를 별도 기록한다. 검증하지 않은 초과 예산/지원 문자를 PASS로 선언하지 않고, 의미를 희생해 폭을 맞추지 않는다.
- 전체 파일을 같은 이름으로 `05_4차_검수_CSV`에 저장하고 재개방하여 **행 수·row_key 유일성·원문·순서·토큰·보호 열·첫/마지막 행·허용 상태값·보류 사유**를 검사한다. 파일마다 진행표 갱신·중간보고 후 승인된 같은 차수 작업을 계속한다.
- 저장한 결과와 출력규격을 [4차](4차.md)에 넘겨 줄바꿈·공란·일본어 잔존을 확인한다. 최종 병합은 4차 후 `06_검수완료`의 채택 결과를 `row_key`로 수행한다. 새 누락은 필요한 행에만 용어 확인과 2→3→4차를 적용한다. 문맥 참고 행을 본문 행으로 합치지 않는다.
- 4차까지 끝난 최종 CSV·병합본·동결 용어 및 인물·관계 기준과 사용 지시문을 로컬 `03_검수_자료/02_검수완료`에 보존한다. 기존 프로젝트의 보관 경로는 임의로 바꾸지 않는다. 언어 검수 완료와 삽입·실기 검증 완료를 구분한다.
