# 공통규칙: 신규 게임의 1차 용어 선확정 → 2차 본번역 → 3차 독립 검수

## 단계와 파일 경로

- **1차는 대사 검수가 아니라 용어 사전 확정**이다. 5종 용어집을 만들고 근거·승인·버전을 기록한다. 별도의 `1차_검수_CSV` 폴더나 초벌 번역 결과는 만들지 않는다.
- **2차는 원문 최초 본번역:** `03_2차_원문_CSV` → `04_3차_검수_CSV`.
- **2차 전체 통합 게이트:** 5종 동결 용어와 화자/캐릭터/관계·말투 근거를 통합한 `01_최신_용어집/3차_확정기준/`을 확정한다.
- **3차는 전 행 독립 원문 재검수:** `04_3차_검수_CSV` → `05_3차_완성본_CSV`. 3차 기준이 없으면 시작하지 않는다.

## 행·스키마와 원문 보존

- 2차·3차는 **같은 대분류의 CSV 1파일**, 기본 헤더 제외 최대 **500논리 데이터 행**을 전부 검수한다. 마지막 파일은 남은 행만 처리한다. 다섯 분류는 캐릭터·아이템·스킬·시스템·대사이며 없는 분류의 가짜 데이터 파일을 생성하지 않는다.
- 대사는 확인된 실제 스토리 순서와 장면·루트를 보존한다. 같은 장면/분기의 앞뒤 2~4문장 및 필요 문맥을 전체 원장/인접 파일에서 읽는다. 다른 분기·미확정 실행 순서를 이어 붙이지 않는다. 읽기 전용 문맥은 데이터 행에 추가하지 않는다.
- `row_key`는 원본 위치와 연결되는 유일한 고정 식별자다. 행 번호·파일명·번역 문구로 재발급하거나 바꾸지 않는다. 같은 문구의 다른 원본 위치는 별도 키로 보존한다.
- 실제 게임의 일본어/영어 원문·언어·순서·토큰·보호 열·제어 구조를 유지한다. 수정은 `게임정보.md`에 정의된 번역/화자/청자/메모/검수 상태 등 **허용된 열에 한정**한다. 원본 파일은 덮어쓰지 않는다.
- `review_status`는 그 게임이 허용하는 값만 사용한다. **대사에 1차 완료를 붙이지 않는다.** 새 2차·3차 상태를 지원하지 않는 기존 스키마는 사용자 승인 아래 대응을 정하고 임의 새 열·값을 만들지 않는다.

## 번역·용어·관계

- **원문을 먼저 읽는다.** 2차는 원문에서 뜻을 해석한 뒤 한국어 본번역하고 기존 번역이 있으면 나중에 비교한다. 3차는 원문에서 독립 판단 후 2차본과 대조한다. 오류 있는 초벌이나 자동 생성 번역을 정답처럼 대하지 않는다.
- 선확정 5종 용어집과 사용자 직접 확정값은 그대로 유지한다. 신규 용어, 의미 충돌, 선확정 오역 의심은 `row_key`·문맥·출처·영향 범위를 갖춘 **정정 후보**로 총괄에게 보고한다. 승인 없이 확정값을 덮어쓰지 않는다.
- 관계·호칭·말투는 실제 대사의 **화자→청자 방향, 이야기 시점·장면·루트, 변화 지점·근거 row_key**로 기록한다. 순간적 감정을 영구 성격으로 만들지 않고 후반 관계를 초반에 소급하지 않는다.
- 서브 작업자는 개인 후보 기록에만 쓴다. 공용 용어집·캐릭터·관계도는 총괄이 충돌·중복을 정리하고 직렬 통합한다. 판단 근거가 부족하면 보류한다.

## 출력·완료·보고

- 정확한 의미를 우선하고 해당 게임에서 **실측 확인한** 최대 줄 수·화면 폭·글리프/인코딩·줄바꿈·RSC만 적용한다. 화면 종류별 규격을 구분하고 모르면 기술 확인 보류로 남긴다.
- 저장 후 재개방해 행 수·고정 키·원문·보호 열·첫 행/마지막 행·보류를 검증하고 진행표를 갱신한다. 전체 2차·기준 통합 이전에는 3차를 시작하지 않는다.
- 2차·3차에서 파일을 마칠 때마다 파일명·처리 행·수정/보류·다음 파일을 중간보고하고 승인된 같은 차수의 다음 파일을 계속 처리한다. 사용자가 1파일만 지정했다면 범위를 늘리지 않는다. **1차는 파일별 대사 완료가 아니라 용어 5종의 확정/보류/승인 현황으로 보고한다.**
- 최종 병합은 `row_key`로 처리한다. **언어 검수 완료와 게임 삽입·실제 플레이 검증 완료는 구분**한다.

## 용어집 조사 순서 — 모든 게임 공통 (사용자 규칙, 2026-10-18)

신규 게임과 진행 중 게임의 미확정 이름·고유명사·용어를 조사할 때 다음 순서를 적용한다.

1. **나무위키·국내 사이트 기사·국내 연재 글 등 한국어 자료**에서 해당 작품·시리즈·인물·개체·개념의 실제 표기를 먼저 확인한다.
2. 국내 자료에서 대응 표기를 찾지 못하면 **실제로 존재하는 해당 게임의 영어판·영문 자료**를 참고한다.
3. 그래도 대응 표기를 찾지 못하면 **국내 다른 게임·애니메이션·소설·만화 등에서 보편적으로 쓰는 이름·고유명사 표기**를 조사한다.

- 다른 작품의 자료는 동일 인물·개체·개념·원어 독음과 실제 게임 문맥이 대응하는 경우에만 적용한다. 철자나 한자가 같다는 이유만으로 다른 대상을 자동 이식하지 않는다.
- 기존 PC AI 한글패치·기계번역은 보조 후보 자료다. 그 표기나 출현 빈도만으로 확정하거나 국내 통용 표기라고 단정하지 않는다.
- 실제 확인한 출처 URL·문서 제목·사용 표기·확인일·대응 근거와 원문·원본 위치·row_key를 남긴다. 검색하지 않은 자료, 존재하지 않는 영어판·공식 번역·사용례를 만들지 않는다.
- 접근 제한이나 검색 실패는 '표기 없음'의 증거가 아니다. 다른 자료를 확인하고, 근거 부족·상충은 미확인/보류와 결정에 필요한 근거로 기록한다.
- 사용자 확정값과 이미 승인·동결한 용어는 보호한다. 이 조사 순서 변경을 기존 확정 용어의 일괄 변경 승인으로 해석하지 않는다. 해당 작업에서 위임된 확정 권한 안에서 선정하며, 미해결 핵심 표기는 묶어서 보고한다.
- 새 프로젝트용 공통규칙·1차 지시문·용어집 출처 양식과 Drive 인계 자료에도 이 순서를 반영한다. 담당 모델이나 게임 기종에 따라 임의로 바꾸지 않는다.
