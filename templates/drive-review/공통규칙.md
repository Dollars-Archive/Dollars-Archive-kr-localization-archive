# 공통규칙

- 한 작업은 **같은 대분류의 CSV 1파일**, 최대 500개 데이터 행이다. 대분류는 캐릭터·아이템·스킬·시스템·대사다. 헤더는 행 수에서 제외하고 읽기 전용 문맥은 별도 열에 넣는다.
- 마지막 파일은 남은 행만 넣는다. 대사는 실제 스토리 순서로 기록하며 같은 장면·분기의 앞뒤 2~4문장을 읽기 전용 문맥 열로 제공한다. 파일 경계의 문맥은 원장·인접 파일에서 확인하고 다른 분기를 이어 붙이지 않는다.
- 원문·row_key·행 수·순서·원래 보호 열을 유지한다. 기존 검수 프로그램의 열 이름을 임의로 바꾸지 않는다.
- `row_key`는 전체 원장에서 유일한 고정 키다. 파일 범위·현재 행 번호·번역 문구로 키를 바꾸거나 재발급하지 않는다. 최종 결과는 이 키로 전체 원장에 매칭하고 보존한 순서를 복원한다. 문맥 참고 문장은 새로운 데이터 행으로 추가하지 않는다.
- 수정은 게임정보.md에 적힌 번역·검수 상태·메모·허용 보강 열에 한정한다.
- 각 행의 일본어·영어 원문과 실제 장면을 기준으로 번역한다. 영어 항목도 검수 대상에 포함하고 원문 언어를 보존한다. 의미·감정·복선·말투를 임의로 바꾸지 않는다.
- 사용자 확정값은 유지한다. 새 용어·인물·관계는 담당 파일별 후보 CSV에 근거 row_key와 함께 기록한다.
- 여러 작업자가 같은 CSV나 공용 용어집을 동시에 덮어쓰지 않는다.
- 후보는 전 파일 처리 후 중복·충돌을 정리해 마스터에 반영한다. 관계는 화자→청자 방향과 적용 장면을 구분한다.
- 각 차수는 전체 데이터를 다시 처리한다. 앞 차수 전체를 처리하거나 보류 사유를 기록한 뒤 다음 차수를 시작한다.
- 원본 입력은 덮어쓰지 않고 같은 파일명으로 다음 폴더에 저장한다.
- 결과는 전체 UTF-8 CSV로 저장한다. 화면에 일부 행만 출력하고 완료라고 하지 않는다.
- 저장 후 행 수·row_key·보호 열·첫 행·마지막 행을 다시 확인한다. 미해결 행은 이유를 남기고 보류한다.
- 게임 화면·픽셀·RSC·진행 검증을 웹에서 못 했으면 실기 확인 대기로 남긴다.
