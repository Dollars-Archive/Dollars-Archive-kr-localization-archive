## 설치 방법

1. 해당 Release의 패치 파일을 내려받습니다.
2. 게임별 실제 패처 실행 순서와 입력 파일을 안내합니다.
3. 생성된 결과 경로와 설치 위치를 적습니다.

## 실행 확인

정상 출력 화면과 확인할 항목을 적습니다.

## 문제 해결
