# Codex·GPT 공통 작업 지시문

이 게임의 한글패치 작업은 [최신 16단계 부트스트랩](https://github.com/Dollars-Archive/Dollars-Archive-kr-localization-archive/blob/main/CODEX-LOCALIZATION-BOOTSTRAP.md)을 따른다. 현재 사용자 지시와 승인 규칙이 우선한다.

1. 시작하기.md에 있는 이 게임의 자료 링크와 진행상태.md를 실제로 읽는다. 지난 채팅의 기억으로 현재 상태를 추측하지 않는다.
2. 현재 단계의 선행 조건을 확인한다. 파일과 확인 근거가 있는 완료 단계는 반복하지 않는다. 미확인 단계는 완료로 처리하지 않는다.
3. 이번 단계에서 필요한 작업만 수행한다. 사용자 승인 규칙이 있으면 그 승인 범위 안에서 진행한다.
4. 결과를 해당 게임의 정해진 위치에 저장하고 다시 열어 확인한다. 진행상태에 단계·파일 링크·검증 결과·사용자 확인·다음 할 일을 기록한다.
5. 실기 확인 단계는 사용자 확인 전까지 대기로 둔다. 테스트 파일, 진입 경로, 조작, 볼 문구·화면과 기대 결과를 안내한다.
6. GPT에 로컬 파일·빌드·실기 도구가 없으면 필요한 작업과 자료를 기록해 Codex/사용자에게 넘긴다. 없는 도구로 실행하거나 저장했다고 말하지 않는다. 이 때문에 앞뒤 순서를 건너뛰지 않는다.
7. Drive 검수는 각 차수의 지시문대로 파일당 최대 500행 전체를 처리한다. 같은 파일명으로 다음 폴더에 저장하고 진행표를 갱신한다. 차수 전체가 끝나면 기준 자료를 정리한 뒤 다음 차수로 간다.
8. 지시문이나 자료에 접근할 수 없으면 필요한 링크와 현재 막힌 지점을 알린다. 읽지 못한 문서를 읽었다고 하거나 완료로 표시하지 않는다.

## 처음 세팅할 때

게임명이 정해지면 기본 폴더부터 만든다. 사용자에게 `00_원본`과 `07_전용 에뮬` 경로를 안내한다. 원본·포터블 복사는 사용자가 한다. 원본이 없다고 경로를 반복해서 묻거나 폴더 생성을 미루지 않는다.

폴더와 시작 안내·진행상태 파일을 만든 뒤 실제 생성 경로를 확인하고 **“폴더 준비 완료”**를 먼저 보고한다. `00_원본`에는 원본 롬, `07_전용 에뮬`에는 포터블 에뮬을 넣도록 안내한다. 준비 보고 전에는 원본 탐색이나 한글패치 여부 조사를 시작하지 않는다. 파일 복사 전에는 원본 등록·전용 에뮬 세팅 대기로 기록하고, 복사 완료 후 등록 파일을 확인해 다음 작업을 진행한다.

- 이 문서를 프로젝트 시작하기.md에서 연결하고 AGENTS.md에도 연결한다.
- `07_전용 에뮬` 폴더를 준비한다. 사용자 포터블 복사 후 게임 테스트용 설정·세이브 경로를 분리하고 실제 저장 경로와 재실행 확인 결과를 진행상태에 기록한다. 도구가 없는 GPT는 설정을 완료했다고 하지 않고 Codex/사용자 확인 대기로 남긴다.
- 게임 저장소 README에는 공통 순서와 시작하기 링크를 연결한다. 비공개 Drive 주소는 공개 README에 넣지 않는다.
- Drive 작업공간에는 이 문서의 본문을 `공통작업지시문.md`, 최신 부트스트랩 본문을 `작업순서.md`로 복사한다. 공통 양식과 진행상태를 함께 올리고 시작하기.md에서 실제 파일 링크를 연결한다.
- 게임별 진행상태는 한 개만 원본으로 사용한다. Drive 준비 후에는 Drive 파일을 원본으로 정하고 로컬에서는 그 링크를 참조한다. 최신 공통 순서가 바뀌면 작업순서.md도 갱신한다.

새 GPT 대화에서도 게임 자료의 시작하기.md를 먼저 읽으면 같은 순서로 이어갈 수 있게 한다. 이 문서를 저장하는 것만으로 모든 새 GPT 대화에 자동 주입되지는 않으므로 게임의 시작 안내와 함께 연결한다.
