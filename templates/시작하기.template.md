# <게임명> 작업 시작하기

Codex와 GPT 모두 먼저 [공통 작업순서](https://github.com/Dollars-Archive/Dollars-Archive-kr-localization-archive/blob/main/CODEX-LOCALIZATION-BOOTSTRAP.md)와 [공통 지시문](https://github.com/Dollars-Archive/Dollars-Archive-kr-localization-archive/blob/main/templates/PROJECT-INSTRUCTIONS.md)을 읽는다. 현재 사용자 지시와 승인 규칙을 우선한다.

게임명이 정해지면 기본 폴더부터 만든다. 사용자에게 `00_원본`과 `07_전용 에뮬` 경로를 안내한다. 원본·포터블 복사는 사용자가 한다. 원본이 없다고 경로를 반복해서 묻거나 폴더 생성을 미루지 않는다.

폴더 준비 완료를 먼저 보고하고 아래 실제 경로를 안내한다. 원본·포터블은 사용자가 복사한다.

- 원본 등록 위치: `D:\Codex\한글화 프로젝트\<게임명>\00_원본`
- 포터블 등록 위치: `D:\Codex\한글화 프로젝트\<게임명>\07_전용 에뮬`
- 진행상태: <현재 단계와 증거를 기록한 파일 링크>
- 게임정보·검증된 출력 규격: <실제 파일 링크>
- 전체 원장: <실제 파일 링크>
- 전용 에뮬: `07_전용 에뮬` — <포터블 복사·설정 분리 상태와 확인 기록>
- 검수 작업공간: <권한에 맞는 링크; 비공개 주소는 공개 저장소에서 제외>
- 기존 성공 자료·사용자 확정값: <실제 파일 링크>

진행상태를 읽고 현재 단계에서 이어서 작업한다. 접근할 수 없는 자료는 필요한 링크를 확인하며, 작업을 완료했다고 추측하지 않는다. 실기 단계는 사용자 확인을 기다린다.
