# 3차 검수 지시문

> 현재 작업은 **3차 최종 정밀검수**다.
> 이 단계는 최종 CSV 반입 직전의 가장 엄격한 언어 검수다.

## 목적

3차는 약 **500행 단위**로 범위를 줄여 문장 하나하나를 깊게 확인한다.

1차의 구조적 기준과 2차의 자연화 결과를 바탕으로 최종 품질을 만든다.

## 우선 확인 항목

- 원문 의미의 정확성
- 미세한 오역
- 뉘앙스
- 앞뒤 대사 문맥
- 감정선의 연속성
- 복선
- 중의적 표현
- 농담과 언어유희
- 캐릭터 일관성
- 호칭과 관계
- 조사
- 어순
- 문장 리듬과 호흡
- 읽기 자연스러움
- 최종 RSC/문자열 길이 제한
- 태그·제어 코드·보호 필드
- 최종 CSV 유효성

## 작업 원칙

1. 공통 기준 자료를 다시 확인하되, 근거 없이 기존 확정 규칙을 뒤집지 않는다.
2. 관계/존대 규칙과 실제 문맥이 충돌하면 근거를 명시해서 수정 후보로 제시한다.
3. 한 문장만 보지 말고 가능하면 앞뒤 문맥과 장면 기능을 함께 본다.
4. 직역과 의역 중 어느 쪽이든 원문의 기능과 캐릭터성을 보존하는 쪽을 선택한다.
5. 캐릭터의 감정 변화와 관계 변화를 평평하게 만들지 않는다.
6. 최종 CSV에 들어갈 수 없는 구조적 변경은 하지 않는다.
7. ID와 보호 필드는 유지한다.

## 최종 출력 기준

3차 결과는 다운로드 후 게임별 검수 프로그램에 바로 반입할 수 있는 상태를 목표로 한다.

최소 조건:

- 안정적인 행 ID 유지
- 필수 컬럼 유지
- 보호 필드 보존
- 한글 번역 필드 최종안 반영
- RSC/문자열 제한 확인
- 미해결 행은 명확한 상태값 또는 비고로 남김

## 완료 기준

3차가 끝난 CSV는 다음 흐름으로 넘어간다.

```text
최종 검수 CSV 다운로드
→ 게임별 검수 프로그램 반입
→ 스키마/ID/보호 필드 검증
→ 패치 데이터 적용
→ 자동 검증
→ 실제 게임 플레이 검수
→ 사용자 확정값 축적
```

실제 플레이에서 확인된 수정은 `workflow/PLAYTEST-FEEDBACK-POLICY.md`의 우선순위를 따른다.
