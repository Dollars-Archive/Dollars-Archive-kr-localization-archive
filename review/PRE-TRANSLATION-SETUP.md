# 번역 전 기준자료·용어집 선세팅 정책

이 문서는 게임 대사 대량 번역을 시작하기 전에 반드시 수행하는 **0단계 기준자료 구축** 정책입니다.

# 핵심 원칙

**용어집·캐릭터·관계·말투를 먼저 만들고, 그다음 대량 대사 번역을 시작합니다.**

번역을 먼저 끝낸 뒤 캐릭터 이름, 반말/존댓말, 호칭, 말투, 고유명사를 전수 수정하는 방식을 기본 흐름으로 삼지 않습니다.

검수 프로그램에 번역 기준자료를 등록할 때도 이 0단계가 먼저입니다.

---

## 1. 고정 검수 파이프라인

대사 검수의 기본 작업 단위는 다음과 같이 유지합니다.

```text
0단계: 기준자료·용어집 구축
→ 1차: 전체 대사집을 약 1,000행 단위로 기초 검수
→ 2차: 1차 결과 전체를 다시 약 1,000행 단위로 자연화·말투 검수
→ 3차: 2차 결과 전체를 다시 약 500행 단위로 최종 정밀검수
→ 게임별 검수 프로그램 반입
→ 실제 게임 플레이 검증
```

`1차=첫 1,000행`, `2차=다음 1,000행`, `3차=그 다음 500행`이라는 뜻이 아닙니다.

각 차수는 **전체 대사집을 다시 훑는 별도 패스**이며 작업 묶음 크기만 1,000 / 1,000 / 500으로 다릅니다.

---

## 2. 대량 번역 시작 전 필수 기준자료

최소한 다음 자료를 게임별로 먼저 준비합니다.

### 고정 용어집

- 캐릭터명·별칭·칭호
- 장소·지역·던전명
- 아이템명
- 시스템 용어
- 스펠·기술명
- 조직·종족·세계관 용어
- 반복적으로 등장하는 핵심 명사

각 항목에는 가능하면 다음을 남깁니다.

```text
일본어 원문
승인 한국어
분류
근거 출처
확정 / 임시 / HOLD 상태
비고
```

### 캐릭터 기준표

최소 권장 정보:

```text
character_id
일본어 공식명
승인 한국어명
별칭·애칭·칭호
성격
기본 말투
1인칭
2인칭/호칭 습관
자주 쓰는 어미·말버릇
감정 표현 경향
피해야 할 표현
승인 예시
근거 출처
확정 상태
```

### 관계도

관계는 **화자 → 청자 방향**으로 관리합니다.

```text
A → B
B → A
```

는 서로 다른 규칙일 수 있습니다.

최소 권장 정보:

```text
speaker
listener
관계
반말 / 존댓말
호칭
상대에 따른 말투
적용 시작/종료 구간
예외
실제 대사 또는 자료 근거
확정 상태
```

### 말투표

- 기본 문장 길이
- 어휘 성향
- 고풍/어린아이/무뚝뚝/정중/독설 등 특징
- 1인칭·2인칭
- 말버릇
- 감정 표현 강도
- 피해야 할 평준화 표현
- 승인 예시 대사

## 3. 캐릭터 이름 조사 순서

캐릭터 이름은 다음 순서로 조사합니다.

1. **사용자가 이미 확정한 프로젝트 표기**
2. **공식 홈페이지·공식 게임·공식 설정 자료**
3. 공식 자료가 일본어뿐이고 한국어 표기가 애매하면 **나무위키의 통용 한국어 표기**를 참고
4. 나무위키에도 없거나 근거가 부족하면 **일본 위키·팬 위키·사전·작품별 자료를 교차 확인**
5. 그래도 애매하면 임의 확정하지 않고 `HOLD`

공식 일본어 이름을 무시하고 영어판 철자만 보고 한국어명을 만들지 않습니다.

공식 한국어 표기가 실제로 존재하면 그것을 우선 검토합니다.

---

## 4. 캐릭터 성격·말투 조사

오래된 게임은 당시 자료가 남아 있는 경우가 많으므로 적극적으로 조사합니다.

우선 조사 대상:

- 공식 캐릭터 소개
- 게임 내 실제 일본어 대사
- 공식 홈페이지
- 매뉴얼·설정집·공략본
- 당시 연재 기사·소개 기사·인터뷰·특집 자료
- 시리즈 공식 자료

보조 자료:

- 나무위키의 성격·인물관계 정리
- 일본 위키·팬 위키의 캐릭터 설명

나무위키와 일본 위키는 **조사 시작점과 교차검증 자료**로 사용할 수 있습니다.
실제 게임 일본어 원문이나 공식 자료와 충돌하면 실제 원문·공식 자료가 우선합니다.

---

## 5. 일본어판과 영어판이 함께 있을 때

**일본어 원문을 기준으로 용어와 대사를 번역합니다.**

영어판은 보조자료입니다.

```text
대사 의미      → 일본어 원문 기준
용어           → 일본어 원문 기준
존대/반말      → 일본어 원문 기준
호칭           → 일본어 원문 기준
캐릭터 말투    → 일본어 원문 기준
영어판         → 의미 확인·문맥 보조·고유명 철자 확인
```

일본어와 영어가 충돌하면 일본어를 따릅니다.

영어판에서 추가·삭제·순화·과장된 농담, 욕설, 설명, 비유를 한국어판에 자동으로 가져오지 않습니다.

---

## 6. 용어 통일은 최우선 합격 조건

대사 번역 전에 **용어 통일 기준을 최대한 고정**합니다.

- 동일 인물의 이름·별명·칭호가 장면마다 흔들리지 않게 합니다.
- 아이템·스킬·던전·시스템·세계관 용어를 통일합니다.
- 같은 일본어 원어·같은 개념이면 승인된 한국어 용어를 우선합니다.
- 비슷해 보여도 다른 일본어 원어를 무조건 하나의 한국어로 뭉치지 않습니다.
- 새 반복 용어를 발견하면 한 행만 고치고 끝내지 말고 용어집 등록 후보로 올립니다.
- 용어집이 실제 일본어 원문과 충돌하면 기존 용어집이라는 이유만으로 자동 KEEP하지 않습니다.
- 사용자가 확정한 용어는 AI가 취향 판단만으로 다시 변경하지 않습니다.

---

## 7. 반말·존댓말·호칭을 번역 전에 강하게 고정

주요 등장인물 사이의 관계는 가능한 한 번역 시작 전에 확정합니다.

반드시 확인:

- A가 B에게 반말인지 존댓말인지
- B가 A에게는 어떤지
- 이름 / 성 / 별명 / 직책 / 씨 / 님 등 호칭
- `さん / さま / ちゃん / くん` 등의 실제 기능
- 처음 만났을 때와 친해진 뒤 변화
- 공적인 자리와 사적인 자리 차이
- 상하관계·연령·조직·가족·친밀도
- 특정 사건 이후 관계 변화
- 예외적인 감정 상태에서만 말투가 무너지는지

자료가 부족하면 실제 일본어 대사의 `です/ます`, 보통체, 명령형, 1·2인칭, 이름 접미사와 호칭을 확인합니다.

근거 없이 관계를 추정해 전체 대사에 적용하지 않습니다.
불확실하면 `HOLD` 또는 `provisional`로 남깁니다.

---

## 8. 검수 프로그램 등록 전 합격 게이트

다음 핵심 기준이 준비되지 않았으면 **검수 프로그램의 본 번역 기준자료 등록을 완료 상태로 표시하지 않습니다.**

- 주요 캐릭터명 표기
- 주요 반복 용어
- 주요 캐릭터 성격·말투
- 주요 화자 → 청자 관계도
- 반말/존댓말 기준
- 호칭 기준
- 일본어 원문과 영어판의 authority 구분
- 미확정 항목 HOLD 목록
- 주요 확정값의 근거 출처

핵심 등장인물과 빈출 용어가 비어 있는데 번역량부터 밀어붙이지 않습니다.

---

## 9. 각 검수 단계의 역할

### 1차: 약 1,000행

기초공사입니다.

- 구조·태그·누락
- 화자/청자
- 관계도·반말/존댓말·호칭
- 캐릭터 말투의 명백한 위반
- 용어 통일
- 명백한 오역
- 새 용어·관계·말투 후보 등록

최종 자연화와 최종 픽셀 줄바꿈은 맡기지 않습니다.

### 2차: 약 1,000행

1차 기준을 유지한 상태에서 자연스러운 한국어와 캐릭터다운 말투를 만듭니다.

- 일본어 직역투 제거
- 캐릭터 어휘·리듬
- 감정 강도
- 장면 흐름과 대사 연결
- 원문의 `[n]` 위치에 끌려가지 않는 한국어 문장 완성

최종 화면 배치는 아직 확정하지 않습니다.

### 3차: 약 500행

가장 꼼꼼한 최종 정밀검수입니다.

- 미세 오역·뉘앙스
- 복선·중의성·농담
- 감정선·캐릭터 일관성
- 조사·어순·호흡
- 최종 `[n]` 배치
- 승인 폰트 기준 실제 픽셀 폭
- 최대 표시 줄 수
- RSC와 보호 명령

세부 화면 배치 규칙은 `review/DIALOGUE-TRANSLATION-POLICY.md`와 `review/REVIEW-STAGE-3.md`를 따릅니다.

# 한 줄 원칙

**번역량보다 먼저 기준을 만든다. 용어·캐릭터·관계·존대를 선세팅한 뒤 1차 1,000행 → 2차 1,000행 → 3차 500행 정밀검수로 진행한다.**
