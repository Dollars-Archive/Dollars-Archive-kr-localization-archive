# 2차 검수 지시문

최신 배포용 [2차 지시문](../templates/drive-review/2차.md)과 [공통규칙](../templates/drive-review/공통규칙.md)을 따른다. 이전의 1,000행·자연화 중심 지침은 사용하지 않는다.

각 행의 **일본어 원문 + 1차 번역본 + 같은 장면·분기의 앞뒤 각각 2~3문장**을 함께 대조한다. 영어 원문 행은 해당 영어 원문을 직접 확인한다. 1차 번역본만 훑고 원문을 확인하지 않은 채 검수 완료로 처리하지 않는다. 화자·청자와 캐릭터 성격·말투·관계를 확인하며 **용어집·고유명사집·인물 관계도·캐릭터별 성격과 말투 기준 완성**에 주력한다. 명백한 오역·누락은 수정하고 **존대·반존대·반말·독백**을 구분해 잘못 적용된 부분을 바로잡는다. 세밀한 어휘·리듬·자연스러운 말투 다듬기는 3차에서 한다. 판단 근거와 적용 장면·시점·방향을 `row_key`로 기록하고, 미확정 후보와 사용자 확정값 충돌은 별도로 남긴다. 3차는 완성된 기준 자료를 바탕으로 작업한다.

기본 작업 단위는 CSV 1파일, 헤더 제외 최대 500행이다.

CSV 1파일(헤더 제외 최대 500행)을 마칠 때마다 결과 저장·재확인·진행표 갱신 후 처리 파일명·행 수·수정/보류 사항·다음 파일을 **중간보고로 남기고, 사용자 응답을 기다리지 않고 승인된 같은 차수의 다음 파일로 즉시 진행한다.** 보고는 작업 중단이나 다음 파일별 재승인 요청이 아니다. 사용자가 1파일만 지정했으면 임의로 범위를 늘리지 않으며, 입력 누락·저장 실패·사용자 판단이 필요한 충돌 등 실제 장애만 이유를 기록하고 확인한다. 차수 전체 종료 후 기준 자료를 통합한 다음 다음 차수로 넘어간다.
