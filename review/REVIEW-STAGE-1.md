# 1차 검수 지시문

> 현재 작업은 **1차 검수**다.
> 1차 목적만 수행하고 2차·3차의 스타일 보정 목표를 임의로 가져오지 않는다.

## 목적

1차는 번역을 예쁘게 다듬는 단계가 아니라 **기초 규칙 생성·확인과 판정의 기초공사**다.

기본 작업 단위는 약 **1,000행**이다.

[대사 번역 공통 원칙](DIALOGUE-TRANSLATION-POLICY.md)을 적용하되 현재 단계의 범위를 넓히지 않는다. 다른 단계 지시문은 읽거나 혼합하지 않는다.

## 우선 확인 항목

- 이미 정의·검증된 RSC 또는 프로젝트별 문자열 길이 제한 초과 여부
- 원문/번역 누락
- 태그, 제어 코드, 플레이스홀더, 구조 개행 손상
- 화자와 청자 식별이 가능한 경우 정확성
- `relationships.csv`에 따른 화자 → 청자 관계
- 반말/존댓말 규칙
- 호칭 규칙
- `speech_style.csv`와 명백히 충돌하는 말투
- `glossary.csv` 고정 용어 불일치
- 의미가 뒤집힌 수준의 명백한 오역
- 후속 단계에서 더 자세히 봐야 할 행 표시

## 작업 원칙

1. 자연스러운 번역을 만들겠다는 이유로 문장을 광범위하게 재작성하지 않는다.
2. 관계도와 말투 규칙에 근거가 있으면 그 근거를 우선한다.
3. 근거가 없는 관계를 추측해서 새 규칙으로 확정하지 않는다.
4. 불확실한 행은 후속 검수 후보로 표시한다.
5. 원문, ID와 보호 필드는 수정하지 않는다. 실제 플레이에서 사용자가 확정한 값은 자동으로 뒤집지 않는다.
6. 게임별 공통 기준 자료와 현재 프로젝트 지시만 사용한다.

## 줄바꿈과 기술 규격의 범위

- 1차에서는 `[n]`을 한국어 문장에 맞춰 재배치하거나 전 행의 픽셀 폭·최대 줄 수를 정밀 검사하지 않는다.
- 게임별 자료에서 이미 검증된 명령 분류만 활용한다. `[n]`이 안전한 배치용 명령인지 모르면 보호 대상으로 유지하고 미확인이라고 기록한다.
- 원문의 `[n]` 위치가 번역문에 그대로 있어야 한다는 최종 배치 규칙을 새로 만들지 않는다. 이미 승인된 배치 예외는 단순 개수 차이만으로 손상이라 판정하지 않는다.
- 가로 픽셀 한계, 자동 줄바꿈, 명령 이동의 안전성, RSC의 실제 의미를 조사하는 기술 검증은 Codex의 별도 작업이다. 1차 검수 묶음마다 재분석하지 않는다.
- 제한이나 검사 도구가 미확정이면 '미확인/검증 대기'로 남긴다. RSC를 글자 수나 화면 폭과 임의로 같은 값으로 취급하지 않는다.

## 1차에서 하지 않을 것

- 전체 문장을 문학적으로 재창작
- 2차 수준의 자연화 작업을 대량 수행
- 3차 수준의 복선/감정선/미세 뉘앙스 해석을 모든 행에 적용
- 관계도에 없는 존대 관계를 임의 확정
- 다른 게임의 말투 규칙을 가져오기
- 최종 `[n]` 재배치, 전 행 픽셀 정밀 배치, 게임 출력 한계의 새 기술 실험

## 완료 기준

1차가 끝났을 때 후속 단계는 최소한 다음을 신뢰할 수 있어야 한다.

- 확인 가능한 범위의 구조가 깨지지 않았다
- 주요 용어가 통일돼 있다
- 확인 가능한 반말/존댓말 규칙이 적용돼 있다
- 명백한 오역과 형식 오류가 걸러졌다
- 더 깊게 볼 행과 기술 규격 미확인 항목이 표시돼 있다

1차 완료는 화면 배치·실제 구동 검증 완료를 뜻하지 않는다.

1,000행이 모델 문맥상 너무 크면 내부적으로 더 작은 묶음으로 나눠 처리할 수 있지만, 사용자에게는 하나의 1차 작업 단위로 관리한다.
